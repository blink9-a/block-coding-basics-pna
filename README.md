# block-coding-basics-pna

## 프로젝트 소개 (Project Overview)
스크래치(Scratch)와 엔트리(Entry)를 활용해 블록 코딩의 기초 개념을 학습하고, 직접 제작한 다양한 프로젝트를 정리하는 저장소입니다.

## 실행 방법 (How to Run)

### 스크래치 (Scratch)
1. [스크래치 홈페이지](https://scratch.mit.edu/projects/editor/)에 접속합니다.
2. **파일 → 컴퓨터에서 불러오기**를 선택하여 `.sb3` 파일을 엽니다.
3. **초록색 깃발 버튼**을 눌러 프로젝트를 실행합니다.

### 엔트리 (Entry)
1. [엔트리 홈페이지](https://playentry.org/)에 접속하여 작품 만들기를 엽니다.
2. **오프라인 작품 불러오기**를 선택하여 `.ent` 파일을 엽니다.
3. **시작하기 버튼**을 눌러 프로젝트를 실행합니다.
